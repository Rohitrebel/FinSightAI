# FinSight AI

FinSight AI is a full-stack financial intelligence and research platform that combines
market data, financial documents, deterministic financial analysis, retrieval-augmented
generation, agentic tools, validation, and AI evaluation.

## Product Roles

### Financial Researcher
Uses FinSight to:

- Explore market data
- Analyze investments
- Review financial metrics
- Upload company documents
- Ask questions about documents
- Generate evidence-backed financial analysis
- Review validation findings
- Export financial and research reports

### AI Ops / Developer
Uses FinSight to:

- Monitor AI services
- Manage document ingestion
- Evaluate retrieval quality
- Compare embedding and chunking strategies
- Manage AI tools
- Monitor semantic caching
- Evaluate model outputs
- Monitor latency and token usage
- Inspect audit trails and decision lineage
